# Mouchard

This repository only hosts the release builds of Mouchard, a macOS HTTP/HTTPS debugging proxy.

Mouchard is in private beta: the app asks for an access code on first launch.

- Website: https://mouchard.app
- Latest version: [Mouchard.dmg](https://github.com/mouchard-app/releases/releases/latest/download/Mouchard.dmg)

Requires macOS 14 or later.
